## Errores encontrados

1. **UnicodeEncodeError en Windows** — Los caracteres `═` (box-drawing Unicode) no son compatibles con cp1252 (encoding del terminal Windows). Solución: `sys.stdout.reconfigure(encoding='utf-8')` + reemplazar con ASCII (`=`, `-`).

2. **403 Forbidden en Airtable API** — PAT válido pero sin workspace asignado. `GET /meta/bases` devolvía `"bases":[]`. Solución: actualizar PAT en airtable.com para incluir el workspace correcto.

---

## Decisiones técnicas

- `carga_24_25.py` es un script dedicado (no usa `main.py`) — más simple y confiable para un mapeo tan específico
- Celular formateado como `+595 0[digits]` (ej: 93307386 → +595 093307386)
- Monto Debido = 450000 por defecto para todos los pagos
- Tuvo Descuento? = True cuando monto_pagado > 0 y < 450000
- Rollup fields en Cohortes NO se pueden crear via API → campos numéricos simples, el script los llena
- Rate limit Airtable: 0.22s de delay entre requests + retry con backoff para errores 429
